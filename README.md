# course-work

My exercises of two courses: Turbo Pascal 7 (2006) and PHP and MySQL (2008). A historical archive, kept read-only:
course work, kept for its history.

## History

One folder per course, each with its own history (joined in 2026 by a merge commit):

| Folder | What | Years | Commits |
|---|---|---|---|
| `pascal-2006/` | Casa, a cash register program (versions 0.0 and 1.0), and Angajare, a hiring exercise: the sources and the compiled programs | 2006 | 3 |
| `php-mysql-2008/` | lessons 1 to 5 (syntax, arrays, loops, forms, files, dates, MySQL) and the course shop: a catalogue with orders and an admin area, with its schema and queries | 2008 | 2 |

The PHP code is the PHP of its time: not safe to deploy today.

## How it was built

There was no version control then: in 2026 I turned the archived folders into commits, dated by the files. The last
commit of each course before the merge sets LF line endings and indents with spaces.
